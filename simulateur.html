Choix du titre — compromis risque/rentabilité (p.95-97)

CV = σ(R)/R̄ : on retient le titre au CV le plus faible. Le CV est non interprétable quand R̄ ≤ 0 (Kering : perte moyenne → écartée sur ce critère, pas « choisie » par un CV négatif). Sharpe = (R̄−Rf)/σ (ex. 38 du fascicule).

Décomposition du risque (p.104, ex. 42) : σ² = β²σM² + spécifique

Matrice de corrélation

Rentabilité exigée — MEDAF + alpha de Jensen RE = Rf + β(RM−Rf) · p.110-112

La prime de risque est une hypothèse documentée : 5 %/an retenus (sources.md §11), testable de 3 à 7 % ci-dessous. Seul le risque de marché est rémunéré (p.110) ; le risque spécifique se gère par diversification.
Alpha de Jensen (p.112) : α = rentabilité réelle − attendue. α > 0 → sous-évalué ; α < 0 → surévalué. Cohérence Bloc B : comparer α au verdict DCF/multiples.

Table de sensibilité à la prime de risque

Portefeuille & diversification p.105-110 · βp = Σwβ

Covariance négative → rentabilités en sens contraire → compensation (p.105). Diversification efficace si ρ < 1 (p.107) ; vraiment efficace au-delà d'une trentaine de titres (p.106) — avec 3 titres on réduit, on n'élimine pas. Formule 2 actifs du cours ; 3ᵉ actif = complément hors cours (docs/programme-cours.md §2).

Couple d'actions — E(Rp), σp, gain de diversification (p.106-107)

Formule du cours à 2 actifs. Le couple le moins corrélé donne le plus grand gain relatif, pas forcément le risque absolu le plus faible — comparez.

Gestion active (portefeuille) vs passive (ETF CAC 40) — p.90-91

Passive = répliquer l'indice (ETF). Active = battre le marché : top-down (macro → secteurs → valeurs de croissance) ou bottom-up (stock-picking value). Sur la fenêtre observée, comparer E(R), σ, CV, Sharpe et β avant de conclure selon le profil.
